# User Stories

1. As a customer or admin, I want to login to the system using my valid user identification and password so that I can access the system according to my role. (FR1)
2. As a customer, I want to browse and select available cookies so that I can choose the products I want to purchase. (FR2)
3. As a customer, I want to view my receipt after successful payment so that I can confirm my purchase and keep a record of my transaction. (FR3)
4. As an admin, I want to add new cookie products to the system so that customers can view and purchase the available cookies. (FR4)
5. As an admin, I want to update the delivery status of customer orders so that customers can receive accurate information about their order progress. (FR5)
6. As a customer or admin, I want the system pages to load within 3 seconds and checkout complete within 5 seconds so that I can use the system efficiently. (NFR1)
7. As a customer, I want my order and payment information to be accurate and consistent so that I can avoid duplicate transactions and incorrect purchase records. (NFR2)
8. As an admin, I want the system to back up data daily and recover from failures wihtin 5 minutes without data loss so that important order and payment records remain protected. (NFR3)
