# Requirements

## Functional requirements 
1. The system shall enable the Customer and Admin to login to the system by supplying valid user identification and password.
2. The system shall enable the Customer to select cookies, specify quantity and add items to cart.
3. The system shall enable the Customer to view receipt after successful payment.
4. The system shall enable the Admin to add new product cookies.
5. The system shall enable the Admin to update delivery status of orders. 

## Non-functional requirements 
1. The system shall load pages within 3 seconds and complete checkout within 5 seconds.
2. The system shall ensure accurate and consistent order and payment data by preventing duplicate transactions.
3. The system shall perform daily backups and recover from failures within 5 minutes without data loss.
