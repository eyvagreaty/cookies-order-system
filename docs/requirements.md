# Requirements

## Functional requirements 
FR01 - Login
The system shall enable the Customer and Admin to login to the system by supplying valid user identification and password.

FR02 - Cookie Ordering
The system shall enable the Customer to select cookies, specify quantity and add items to cart.

FR03 - Receipt
The system shall enable the Customer to view receipt after successful payment.

FR04 - Product Management
The system shall enable the Admin to add new product cookies.

FR05 - Delivery Management
The system shall enable the Admin to update delivery status of orders. 

## Non-functional requirements 
NF01 - Performance 
The system shall load pages within 3 seconds and complete checkout within 5 seconds.

NFR02 - Data Integrity
The system shall ensure accurate and consistent order and payment data by preventing duplicate transactions.

NFR03 - Backup and Recovery 
The system shall perform daily backups and recover from failures within 5 minutes without data loss.
